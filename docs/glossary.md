# Glossary

| Term | Definition |
| --- | --- |
| Amcache | A Windows application compatibility and inventory artifact stored in `Amcache.hve`, useful for program path and metadata context. |
| Artifact | A data source created by an operating system, application, file system, or security product that can support investigation. |
| Attribution | The act of identifying the responsible account, process, system, or actor. Attribution requires correlation and should not be inferred from one artifact alone. |
| EDR | Endpoint Detection and Response telemetry, usually including process, file, registry, network, and alert data. |
| Evidence | A recorded fact or artifact that supports or challenges an investigative claim. |
| Inference | A reasoned interpretation drawn from evidence. Inferences should be labeled and tested. |
| LNK | Windows Shell Link shortcut file. LNK files can preserve target path, volume, timestamp, and argument information. |
| MFT | Master File Table, the central NTFS metadata structure for files and directories. |
| Observation | A direct statement of what an artifact or tool output shows before interpretation. |
| Prefetch | A Windows performance artifact that can provide execution-related evidence for programs. |
| RDP | Remote Desktop Protocol, commonly investigated through Security and Terminal Services event logs. |
| ShimCache | Application Compatibility Cache, a Windows compatibility artifact that can preserve executable path evidence. |
| SRUM | System Resource Usage Monitor, an ESE database containing resource usage data, including network usage context. |
| Timestomping | Modification of file timestamps to mislead investigators or blend malicious files with legitimate files. |
| USN Change Journal | NTFS journal that records file system change activity on a volume. |
| WMI | Windows Management Instrumentation, a management framework that can be abused for persistence and remote execution. |
| Zone.Identifier | Alternate data stream commonly used to preserve Mark-of-the-Web source zone and URL context. |
